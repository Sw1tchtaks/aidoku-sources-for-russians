# Senkuro (ru.senkuro)

Источник для [Senkuro](https://senkuro.com): манга, манхва, маньхуа и комиксы на русском языке.

## Возможности

- Актуальный каталог и поиск через ту же GraphQL-выдачу `mangas`, которую использует сайт; курсорная пагинация сохраняет непрерывную прокрутку.
- Запросы передают официальный `App-Id` Senkuro, поэтому каталог и набор меток не смешиваются с отдельным приложением Senkognito.
- Домашняя страница с топом за день, неделю и месяц, последними обновлениями, новыми тайтлами и разделами по типам.
- Карточка, команды переводчиков, главы и страницы для чтения.
- Сортировка по популярности, рейтингу, главам, просмотрам и датам.
- Фильтры типа, формата, статусов, рейтинга, числа глав, года, первоисточника и страны.
- Семь групп меток берутся из актуального `allLabels`; устаревшие метки старого Tachiyomi-справочника не показываются.
- Прямые ссылки вида `/manga/<slug>` разрешаются в полный ID через поиск API.

Общий движок Senkuro и Senkognito находится в [`templates/senkuro`](../../templates/senkuro). Рабочий публичный API: `https://api.senkuro.com/graphql`.

## Настройки

- **Домен API** — `api.senkuro.me` предназначен для России, `api.senkuro.com` — для зарубежных сетей и VPN. При сетевой ошибке источник автоматически повторяет запрос через второй API независимо от выбранного варианта.
- **Английские заголовки** — использовать английские названия и подписи вместо русских, когда они доступны.

Senkuro скрывает все метки с рейтингом `EXPLICIT`, включая эротику, хентай, яой, юри, сёнен-ай и сёдзе-ай. Для хентая предназначен отдельный источник Senkognito.
