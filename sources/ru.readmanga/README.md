# ReadManga (ru.readmanga)

Источник ReadManga на движке Grouple. Основной рабочий адрес — `a.zazaza.me`; для зарубежной сети и VPN также доступен `readmanga.me`.

## Реализация

Логика общая с MintManga / SelfManga / AllHentai — вынесена в [`templates/grouple`](../../templates/grouple). Источник — тонкая обёртка с `DEFAULT_BASE_URL`.

В текущей версии:

- Домашняя страница: большая витрина, «Ещё популярное», «Последние обновления» и «Новинки».
- Каталог: «Популярное» / «Последние обновления» / «Новинки» через `/list?sortType=...`
- Поиск: `/search/advancedResults?q=...` (без расширенных фильтров пока)
- Список глав: парсится из таблицы `tr.item-row`, `?d=user_hash&mtr=true` подкладывается из inline-скрипта
- Чтение: страницы извлекаются из `rm_h.readerInit(...)` / `rm_h.readerDoInit(...)` ручным сканером (без regex-крейта, чтобы не раздувать .aix)

## Настройки

- **Сайт** — `a.zazaza.me` работает из России и зарубежных сетей; `readmanga.me` оставлен как дополнительный вариант для VPN.
- **Войти через WebView** — единственный включённый способ авторизации. Ручные Cookies и Auth Token не используются, поскольку сайт не принимает их стабильно.

## Известные ограничения

- Нет фильтров по жанрам, категориям, возрасту и сортировке (`filters.json` пуст).
- Лицензированные тайтлы и платные главы могут требовать действующий вход через WebView.
- Дата главы парсится по `dd.MM.yy` / `dd/MM/yy` в UTC midnight; локального TZ нет.
