# Senkognito (ru.senkognito)

Источник 18+ для [Senkognito](https://senkognito.com), использующий отдельный каталог приложения Senkognito в GraphQL API.

## Возможности

- Все запросы отправляют официальный `App-Id` Senkognito. Это отделяет хентай-каталог от обычного каталога Senkuro и убирает посторонние OEL-комиксы.
- Каталог и поиск ограничены рейтингом `EXPLICIT`, но не добавляют скрытую метку `hentai`: выбранные пользователем хентайные темы теперь работают так же, как на сайте, без ложных пустых пересечений.
- Домашняя страница содержит популярное, свежие главы, новые тайтлы и отдельные разделы манги, манхвы и маньхуа; общий раздел обычных комиксов скрыт.
- Сортировка и фильтры сайта: тип, формат, статусы, рейтинг, число глав, год, первоисточник и страна.
- Динамические фильтры используют актуальный справочник сайта, включая 42 действующие хентайные темы вместо сотен устаревших меток старого Tachiyomi API.
- Карточки, главы, страницы для чтения и прямые ссылки `/manga/<slug>`.

Общий движок находится в [`templates/senkuro`](../../templates/senkuro). Основной API: `https://api.senkognito.com/graphql`; резервный `https://api.senkuro.com/graphql` возвращает тот же каталог при передаче `App-Id` Senkognito.

## Настройки

- **Домен API** — основной `api.senkognito.com` или резервный `api.senkuro.com`. Источник автоматически пробует второй адрес при сетевой ошибке. `api.senkuro.me` не предлагается, поскольку для приложения Senkognito он отвечает `403`.
- **Английские заголовки** — использовать английские названия и подписи, когда они доступны.
