# MangaBuff (ru.mangabuff)

Источник для [MangaBuff](https://mangabuff.ru) с каталогом русских переводов манги, манхвы и маньхуа.

## Возможности

- Главная страница использует живые разделы сайта: популярное, горячие новинки и недавно добавленные тайтлы.
- Из «Горячих новинок» и «Нового на сайте» можно открыть полную подборку из 20 карточек.
- Для шести видимых карточек в разделах «Горячие новинки» и «Новое на сайте» дополнительно загружается полный набор возрастных, жанровых и сюжетных тегов; верхняя витрина также получает описание и все теги.
- Оригинальные обложки используются по умолчанию; экономичные миниатюры 180 px можно включить в настройках.
- Доступны отдельные каталоги `Манга`, `Манхва`, `Маньхуа` и общий каталог с пагинацией.
- Поиск: `GET /search?query=…&page=N`.
- Карточка и главы: `GET /manga/{slug}`.
- Страницы главы извлекаются из `div.reader__item img[data-src]`.

## Выбор домена

В настройках источника можно выбрать:

- `https://mangabuff.ru` — основной сайт, рекомендуемый также при VPN;
- `https://wss.mangabuff.ru` — резерв для российских сетей;
- `https://wss2.mangabuff.ru` — второй резерв для российских сетей.

Выбранный домен применяется к главной, каталогам, поиску, карточкам, главам, внутренним ссылкам и `Referer` изображений. Проверка из России, Германии и США показала, что `wss`-зеркала из-за рубежа часто отвечают `403` и могут очень медленно отдавать HTML, поэтому для VPN сначала используйте основной домен.

## Ограничения

- Авторизация не реализована: закрытые или доступные только подписчикам главы могут не открыться.
- `Viewer::Webtoon` используется по умолчанию, поскольку большая часть каталога рассчитана на вертикальное чтение.
