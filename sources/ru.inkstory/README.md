# InkStory

Источник для [inkstory.net](https://inkstory.net/).

## Что работает

- красивое домашнее меню: популярное за день, продолжение подборки, недельный топ, обновления, новинки, манга, манхва и маньхуа;
- поиск по каталогу InkStory;
- страницы тайтлов, обложки, описание, теги, статус и список глав;
- чтение глав через API InkStory;
- авторизация через WebView, ручной Cookie и Access Token.

## Авторизация

Публичный каталог открывается без входа. Если нужен аккаунт, используйте настройки источника:

1. **Войти через WebView** — обычный вход на сайте.
2. **Cookies из браузера** — самый надежный способ, если WebView не удерживает сессию.
3. **Access Token** — запасной вариант для API-запросов.
